
# 📊 E-Commerce Data Visualization Project

This project presents a visual analytics solution for e-commerce data using **Power BI** and **ParaView**. It explores sales trends, customer behavior, and product category performance through both 2D and 3D visualizations.

## 🔎 Preview

![Dashboard Preview](./Screenshot%202024-04-30%20165741.png)

## 🧰 Tools & Technologies
- **Power BI** – For interactive dashboard design and KPI tracking  
- **ParaView** – For 3D glyph-based visualizations and spatial data insights  
- **Microsoft Excel / CSV** – As a base data source  
- **DAX & Filters** – For custom metrics and dynamic visuals

## 🔍 Key Features
- Interactive dashboards with filters and slicers for:
  - Sales, Profit, Quantity, and AOV
  - State-wise and category-wise performance
  - Drill-down and brushing features
- 3D glyphs in ParaView visualizing:
  - Profit, Quantity, Category (XYZ Mapping)
  - Color-coded payment modes
  - Scaled shapes based on business performance

## 📁 File Included
- `ECommerce Dashboard.pbix` – Main Power BI dashboard file

## 📌 Project Outcome
This project demonstrates the power of combining traditional BI dashboards with 3D spatial exploration. It highlights how data storytelling can be enhanced by multi-dimensional views for better business decisions.
